# AI Job Research Agent · 求职尽调 Agent

一个轻量的 **AI 求职尽调助手**：读取岗位描述（JD）→ 提取共同要求 → 保留来源 → 对照个人经历 → 生成能力差距分析。

---

## 📌 项目定位

在投递简历前，用 AI 帮你回答三个问题：

1. **这些岗位到底要什么？** —— 从多份 JD 中提取高频共同要求
2. **信息从哪来？** —— 每条要求都保留来源（公司 / 岗位 / 原文片段）
3. **我差在哪？** —— 对照个人经历，输出结构化的能力差距分析

---

## 🎯 核心功能

| 功能 | 说明 |
|------|------|
| 📄 JD 解析 | 读取岗位描述文本/文件，结构化抽取技能、经验、学历等要求 |
| 🔁 共同要求提取 | 多份 JD 交叉比对，找出高频/共性要求并排序 |
| 🔗 来源追溯 | 每条结论标注来源 JD，可回溯原文片段 |
| 🧍 个人经历对照 | 输入个人简历/经历，逐条匹配岗位要求 |
| 📊 差距分析 | 输出「已具备 / 部分具备 / 缺失」三级能力差距报告 |
