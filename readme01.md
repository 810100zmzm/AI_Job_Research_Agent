# AI 求职尽调 Agent · 立项说明（v2）

## 要解决的痛点

做过一些 AI 项目，却卡在最后一步：

1. 不知道**哪个项目真正适合写进简历**去投 AI 工程师开发岗；
2. 担心写进去的项目**经不起面试追问**。

## 这个版本只做一件事

> 输入：一份 JD + 一个项目描述
> 输出：这个项目**值不值得写进简历**（2~3 条理由 + 1~2 个风险 + 建议写法）+ 可检查的运行 Trace

## 它怎么保证不瞎说

- 每条理由、每个风险都带 `文件::L行号`，能回到原文；
- 资料不足就停下来问**一个**问题（`Ask`），不替用户猜；
- 证据够了才下结论（`Stop`），并写明 `StopReason`；
- 每完成一步都记录 `Action / Observation / State Update / Decision`，下一步只能选 `Continue / Adjust / Ask / Stop`。

## 版本取舍

v1 做的是「多份 JD 交叉比对 → 共同要求 → 对照简历找差距」。
它回答的是「这个岗位群大概要什么」，但没有回答用户真正卡住的那个问题，所以 v2 收敛成一条主线：

**一个项目，对一份 JD，回答「写不写」。**

代价是砍掉了多 JD 统计与简历解析；换来的是每一步都可解释、可检查、可复现。

## 后续可以加（本版本刻意不做）

- 多个项目横向排序，直接回答「先写哪个」；
- 面试问题预演：按缺失项生成最可能被追问的 3 个问题；
- 用大模型润色报告文字（当前刻意保持纯规则，保证结论可追溯）。
