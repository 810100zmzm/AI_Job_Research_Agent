### 智能旅行助手 Agent ｜ 全栈开发

**技术栈**：Vue3 + TypeScript、FastAPI、HelloAgents、高德地图 API、Python

**项目描述**：一个基于多智能体协作的智能旅行助手，用户输入出行需求后，由多个专门 Agent 协同完成任务分解、工具调用与结果整合，最终输出行程方案并在地图上可视化展示。

**系统架构（四层设计）**：

- **前端层（Vue3 + TypeScript）**：负责用户交互和数据展示，包括表单输入、结果展示、地图可视化。
- **后端层（FastAPI）**：负责 API 路由、数据验证、业务逻辑。
- **智能体层（HelloAgents）**：负责任务分解、工具调用、结果整合，包含 **4 个专门的 Agent**。
- **外部服务层**：提供数据和能力，包括**高德地图 API**。

**个人职责与技术实现**：

- 参与四层架构设计与联调，打通前端、后端、智能体层与外部服务层的数据链路；
- 基于 **FastAPI** 实现 API 路由、请求数据验证与业务逻辑处理；
- 基于 **HelloAgents** 编排 4 个专门 Agent，实现任务分解、工具调用与结果整合；
- 对接 **高德地图 API**，实现地点检索、路线规划等能力接入；
- 前端使用 **Vue3 + TypeScript** 完成表单输入、结果展示与地图可视化交互。

### 基于 SpringBoot 的蛋糕店点餐系统 ｜ 后端核心功能开发

**技术栈**：SpringBoot、SpringMVC、Spring、MyBatis、MySQL、Redis、JWT、WebSocket、Nginx、Swagger、阿里云 OSS、ECharts

**项目描述**：项目包含管理端与客户端，遵循 `controller-service-mapper` 分层开发结构，以数据增删改查为主，覆盖员工管理、蛋糕商品管理、套餐组合管理、购物车管理、订单统计等核心业务模块，支撑商家日常运营与用户点餐流程。

**具体技术与实现**：

- 基于 **MyBatis** 完成数据库增删改查操作，实现员工、蛋糕、套餐等数据的精准管理。
- 使用 **JWT + ThreadLocal + 拦截器** 实现接口权限校验：JWT 生成用户令牌，登录后返回浏览器；后续请求通过 Interceptor 拦截并解析 Token，将用户信息存入 ThreadLocal，实现请求链路内无感传递用户上下文，避免重复查询数据库。
- 使用 **Redis** 缓存店铺状态、热门蛋糕等高频访问数据，通过返回空值避免缓存穿透。
- 利用 **SpringTask 定时任务** 实现超时未支付订单自动取消，提高运营效率。
- 基于 **阿里云 OSS** 构建静态资源存储方案，支持蛋糕图片大批量上传，提升加载效率与管理便捷性。
- 基于 **Nginx** 构建反向代理与负载均衡机制，部署静态资源，提升系统稳定性与响应速度。
- 用 **AOP** 技术自动填充创建时间、修改人等公共字段，简化重复开发工作。
- **Apache ECharts** 实现营业额统计、用户统计、订单统计及销量排名统计，为商家提供可视化运营数据。
- **Swagger** 生成标准接口文档，方便前后端联调与接口维护。
