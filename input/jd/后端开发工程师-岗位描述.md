## 岗位职责

1. 负责公司核心业务系统的后端架构设计与开发，保障系统的高可用、高性能与可扩展性；
2. 参与需求分析、技术方案设计、接口设计及数据库设计，输出高质量技术文档；
3. 负责服务端接口开发、业务逻辑实现及第三方系统对接；
4. 持续优化系统性能，排查并解决线上问题，提升系统稳定性；
5. 参与代码评审，推动团队编码规范与工程最佳实践落地；
6. 与产品、前端、测试、运维等团队紧密协作，保障项目按时高质量交付；
7. 关注后端技术发展趋势，参与技术选型与架构演进。

## 任职要求

### 基本要求

- 本科及以上学历，计算机、软件工程或相关专业；
- [3] 年以上后端开发经验；
- 扎实的计算机基础，熟悉数据结构、算法、操作系统、计算机网络；
- 熟悉至少一种主流后端语言：**Java / Go / Python / Node.js / C++**；
- 熟悉常用 Web 框架，如 Spring Boot、Gin、Django、Express 等；
- 熟悉 MySQL、PostgreSQL 等关系型数据库，具备 SQL 优化能力；
- 熟悉 Redis、消息队列（Kafka / RabbitMQ / RocketMQ）等中间件；
- 熟悉 RESTful API 设计，了解微服务架构；
- 熟悉 Linux 开发环境，掌握 Git 等版本管理工具。

### 加分项

- 有高并发、分布式系统开发经验；
- 熟悉 Docker、Kubernetes 等容器化与云原生技术；
- 有云平台（AWS / 阿里云 / 腾讯云）使用经验；
- 熟悉 Elasticsearch、ClickHouse 等数据存储与检索组件；
- 有开源项目贡献或技术博客输出；
- 具备良好的英文技术文档阅读能力。

## 能力素质

- 良好的问题分析与解决能力，能独立承担模块开发；
- 较强的责任心与主动性，具备良好的团队协作意识；
- 良好的沟通能力，能清晰表达技术方案与设计思路；
- 具备持续学习能力，对技术有热情。
