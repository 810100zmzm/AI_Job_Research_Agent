# AI算法实习生（日常实习/秋招可投）
**岗位类型**：在校实习 / 暑期实习 / 秋招应届生
**工作地点**：一线互联网城市（远程/线下均可适配）

## 岗位职责
- 协助算法工程师完成AI模型的数据处理、数据清洗、样本筛选与数据集整理工作，保障模型训练数据质量。
- 参与机器学习、深度学习模型的基础训练、参数调优、结果对比与实验复盘，记录实验日志。
- 跟进NLP/CV/大模型任一方向基础任务，协助完成模型微调、Prompt优化、简单RAG场景测试。
- 整理模型迭代文档、技术调研笔记，跟进前沿AI技术、论文与开源项目，输出学习总结。
- 配合团队完成算法效果评估、问题复盘，协助优化模型准确率、推理稳定性。

## 任职要求
- 本科及以上在读，计算机、人工智能、软件工程、数学、统计等相关专业，25-27届应届生优先。
- 熟练掌握Python基础，了解PyTorch/TensorFlow任一深度学习框架。
- 掌握机器学习基础理论（分类、回归、聚类、神经网络等），有课程项目、竞赛、科研项目经验即可。
- 了解大模型、微调、RAG基础概念，有相关课程作业或个人项目加分。
- 学习能力强，耐心细致，能稳定实习2个月以上，可快速上手落地任务。

## 加分项
- 有Kaggle、数模、AI竞赛参赛/获奖经历
- 有开源项目、大模型微调、知识库搭建个人作品
- 熟练使用Linux基础命令、Git版本管理
