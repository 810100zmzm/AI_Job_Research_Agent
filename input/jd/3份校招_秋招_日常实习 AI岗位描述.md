# 3份校招/秋招/日常实习 AI岗位描述（适配学生投递）

## 岗位一：AI算法实习生（日常实习/秋招可投）

**岗位类型**：在校实习 / 暑期实习 / 秋招应届生

**工作地点**：一线互联网城市（远程/线下均可适配）

**岗位职责**

- 协助算法工程师完成AI模型的数据处理、数据清洗、样本筛选与数据集整理工作，保障模型训练数据质量。

- 参与机器学习、深度学习模型的基础训练、参数调优、结果对比与实验复盘，记录实验日志。

- 跟进NLP/CV/大模型任一方向基础任务，协助完成模型微调、Prompt优化、简单RAG场景测试。

- 整理模型迭代文档、技术调研笔记，跟进前沿AI技术、论文与开源项目，输出学习总结。

- 配合团队完成算法效果评估、问题复盘，协助优化模型准确率、推理稳定性。

**任职要求**

- 本科及以上在读，计算机、人工智能、软件工程、数学、统计等相关专业，25\-27届应届生优先。

- 熟练掌握Python基础，了解PyTorch/TensorFlow任一深度学习框架。

- 掌握机器学习基础理论（分类、回归、聚类、神经网络等），有课程项目、竞赛、科研项目经验即可。

- 了解大模型、微调、RAG基础概念，有相关课程作业或个人项目加分。

- 学习能力强，耐心细致，能稳定实习2个月以上，可快速上手落地任务。

**加分项**

- 有Kaggle、数模、AI竞赛参赛/获奖经历

- 有开源项目、大模型微调、知识库搭建个人作品

- 熟练使用Linux基础命令、Git版本管理

## 岗位二：AI大模型应用开发实习生（校招/实习）

**岗位类型**：在校实习 / 暑期实习 / 秋招应届生

**工作地点**：互联网科技企业，支持远程/线下

**岗位职责**

- 协助团队进行大模型应用开发与调试，参与智能问答、知识库RAG、AI助手等轻量化业务功能开发。

- 负责Prompt优化、对话逻辑调试、向量数据库基础使用，辅助完成知识库录入、检索优化。

- 协助开发、封装基础模型接口，完成功能联调、BUG修复、测试验证工作。

- 整理开发文档、使用手册，跟进AI应用线上效果，记录问题并协助迭代优化。

- 调研主流大模型应用方案、开源框架（LangChain/LlamaIndex），输出技术学习总结。

**任职要求**

- 本科及以上在读，计算机、电子信息、软件工程等相关专业，25\-27届学生均可。

- 熟练使用Python，了解FastAPI/Flask等基础Web开发框架。

- 熟悉大模型基础原理，了解RAG、向量数据库、Prompt工程基础内容。

- 具备基本的代码调试、问题排查能力，有个人AI小项目优先。

- 态度踏实，主动学习，能长期稳定实习，适配团队开发节奏。

**加分项**

- 独立搭建过简易RAG知识库、AI对话小程序

- 掌握前端基础、可参与简单全栈开发

- 熟悉Docker基础部署流程

## 岗位三：AI产品实习生（校招/实习专属）

**岗位类型**：在校实习 / 暑期实习 / 秋招应届生

**工作地点**：互联网/AI科技公司

**岗位职责**

- 协助AI产品经理进行行业调研、用户需求梳理，整理AI产品竞品分析报告（大模型工具、AI助手、AIGC产品等）。

- 辅助撰写产品PRD、需求文档、功能原型说明，梳理AI产品功能流程、交互逻辑。

- 跟进AI功能迭代，对接算法、研发团队，同步需求、跟进开发进度、协助测试验收。

- 收集用户使用反馈，整理产品问题清单，协助优化Prompt策略、知识库内容、产品功能体验。

- 统计产品核心数据，输出日常数据复盘、迭代总结，协助完成产品季度迭代规划。

**任职要求**

- 本科及以上在读，专业不限，产品、经管、计算机相关专业优先，25\-27届应届生可投。

- 对大模型、AIGC、AI智能产品有浓厚兴趣，了解基础AI行业知识。

- 逻辑清晰、擅长文档撰写、信息整理，会使用Axure/墨刀、Excel数据分析优先。

- 沟通能力良好，擅长跨团队对接，执行力强，能快速接收新知识。

- 有无产品经验均可，接受零基础优秀在校生。

**加分项**

- 有互联网实习、产品项目、校园项目运营经验

- 熟悉Prompt调优、用过各类AI工具并深度体验

- 具备基础数据分析、SQL使用能力
